# 04 产品需求规格说明书（PRD）

> 版本：`v0.1`（P0 设计基线）
> 最后更新：2026-09-20
> 责任人：成员 B（协作：成员 A）
> 变更规则：任何新增功能必须先修改本文件、数据模型和验收清单，再进入代码。

## 1. 用户角色

| 角色 | 描述 | 关键诉求 |
|---|---|---|
| 普通用户 | 对隐私有关注但不理解日志/域名 | 一句话看懂、可操作 |
| 演示人员 | 现场跑通演示闭环 | 稳定、可重复、证据可展开 |
| 评审专家 | 判断创新性与技术真实性 | 数据可追溯、边界诚实、可复现评测 |

## 2. 用户故事（优先级从高到低）

| 编号 | 用户故事 |
|---|---|
| US-1 | 作为普通用户，我想知道某个 App 为什么在后台读取网络数据，以便判断是否可信。 |
| US-2 | 作为普通用户，我想知道一个行为是否与我当前正在使用的场景匹配。 |
| US-3 | 作为普通用户，我想看到评判结论的依据和证据，以便自己判断。 |
| US-4 | 作为普通用户，我想知道具体该怎么处置（改哪个设置），且处置可逆。 |
| US-5 | 作为普通用户，我想知道处置后异常行为是否真的减少了。 |
| US-6 | 作为演示人员，我想用可重复的 Demo 场景展示完整闭环而不依赖在线服务。 |

## 3. 核心场景与主流程

主演示案例确定为：**后台读取剪贴板/位置相关场景与网络行为解释**。

```text
首次启动 -> 权限与隐私说明 -> 用户授权可观测能力
  -> 运行监测 -> 收到实时告警 -> 查看事件解释
  -> 查看 App 风险画像 -> 查看每日摘要
  -> 执行系统设置建议 -> 复查处置后的变化
```

## 4. 事件类型（P0）

| 类型 | 说明 | 可观测性 | 来源 |
|---|---|---|---|
| `network` | VPN 观测到的网络连接 | E2 授权观测 | VpnService |
| `usage_context` | 前后台/近期使用 | E2 授权观测 | UsageStatsManager |
| `clipboard` | 后台读取剪贴板 | E4 演示真值 | Demo App |
| `location` | 位置相关调用 | E4 演示真值 | Demo App |
| `contacts` | 通讯录访问 | E4 演示真值 | Demo App |
| `permission` | 授权状态变化 | E1 系统事实 | PackageManager |

## 5. 功能需求（P0）

### F1 首次授权引导

- **输入**：用户首次启动。
- **处理**：逐项说明并申请通知、Usage Access、VPN 权限。
- **输出**：授权状态页；未授权项显示“待授权”，拒绝有降级提示。
- **异常**：任一项拒绝不闪退；可恢复。

### F2 App 能力画像（P0-2）

- **输入**：包名 / UID / 版本 / 声明权限 / 授权状态。
- **处理**：`PackageManager` 读取并去重展示。
- **输出**：App 列表、单个 App 的权限与场景类型、网络访问聚合。
- **边界**：只展示系统可见 App；不声称“使用了权限”。

### F3 使用上下文（P0-3）

- **输入**：UsageStatsManager 的包名、时间、前后台、交互事件。
- **处理**：判断某时刻 App 处于前台、后台、近期使用、长时间未使用。
- **输出**：`foregroundState`。
- **降级**：无 Usage Access 时标记“使用上下文不可用”，结论等级降低。

### F4 VPN 网络观测（P0-4）

- **输入**：VpnService 的 IP、端口、协议、时间、流量、UID。
- **处理**：UID→包名映射；尝试域名线索；记录原始连接元数据。
- **输出**：`NetworkEvent`。
- **边界**：域名不可见时只显示 IP；不得查看请求体。
- **异常**：UID 无法归属显示“无法归属”；VPN 被回收时降级。

### F5 统一事件时间线（P0-5）

- **输入**：所有事件（真实 + 演示）。
- **处理**：写入本地事件库；去重；按时间逆序；频率聚合。
- **输出**：事件列表、事件详情。
- **边界**：演示事件带标识；事件可追溯来源。
- **异常**：重启后历史数据不丢失。

### F6 本地规则引擎（P0-6）

- **输入**：事件 + App 画像 + 使用上下文。
- **处理**：应用 5-10 条本地规则，产出分类、风险等级、置信度、场景一致性。
- **输出**：`RiskAssessment`。
- **边界**：规则不修改原始事件；同版本同输入输出稳定。
- **规则示例**：计算器后台联网持续高频 → 高风险；地图前台使用定位 → 合理。

### F7 证据卡片（P0-7）

- **输入**：`EvidenceLink` + 证据等级。
- **处理**：把与结论相关的证据聚合为可展开卡片。
- **输出**：证据等级（E1-E5）、来源、时间、内容摘要。
- **边界**：证据不足时输出“无法确认”，不强行给高风险结论。

### F8 域名/App 阻断（P0-8）

- **输入**：阻断配置（域名或 App）。
- **处理**：VPN 转发核心命中阻断规则并断开/记录。
- **输出**：阻断记录、是否生效、被阻断后仍有尝试。
- **边界**：只阻断网络通道，不修改其他 App 的权限。
- **异常**：记录“尝试被阻断”“已生效”或“无法确认”。

### F9 处置后复查（P0-9）

- **输入**：处置前快照 + 处置后观察窗口内的事件。
- **处理**：对比处置前后同类行为发生频率。
- **输出**：对比报告（“已减少”“无变化”“无法确认”）。
- **边界**：不承诺用户预期的结果，诚实显示。

### F10 Demo 演示沙箱（P0-10）

- **输入**：自研 Demo App 触发受控行为。
- **处理**：生成带真值的演示事件；可重复；可重置。
- **输出**：4 个场景真值。
- **边界**：界面标注“演示数据”；不冒充真实系统数据。

## 6. 页面需求（P0）

| 页面 | 内容 |
|---|---|
| 首页/总览 | 监测状态、风险等级、今日事件数、最近告警卡片 |
| 实时告警弹层 | App、行为、时间、前后台、风险级别、查看详情/稍后处理 |
| 事件列表 | 时间线、过滤、演示/真实标识、风险、证据展开 |
| 事件详情 | 事实、证据来源/等级、分类、置信度、“为什么这样判断”、建议 |
| App 画像 | 权限状态、场景类型、网络访问聚合、阻断操作 |
| 设置/隐私控制 | 监测开关、事件保留天数、AI 开关、数据删除、来源与版本 |

## 7. 非功能需求

| 类别 | 要求 |
|---|---|
| 稳定性 | 拒绝权限、断网、VPN 被回收时不闪退，有降级提示 |
| 响应 | 告警生成后及时通知；列表流畅 |
| 本地优先 | 原始事件尽量只存本地；断网时核心分析可用 |
| 合规 | 剪贴板/通讯录原文不持久化；云端请求前字段白名单过滤 |
| 可追溯 | 每条结论都能回到原始事件、时间、应用和证据 |
| 一致性 | 同一输入在相同规则版本下输出稳定；APK 与文档版本一致 |

## 8. 异常流程汇总

拒绝 Usage Access、拒绝 VPN、无域名、断网、VPN 被回收、UID 无法归属、权限被撤销、启动时授权状态变化。详见 [03-permission-and-consent-flow.md](03-permission-and-consent-flow.md)。

## 9. 数据边界

- **保存**：事件元数据、风险结果、处置记录、规则版本、App 画像。
- **不保存**：剪贴板原文、通讯录内容、精确位置轨迹、聊天内容。
- **脱敏**：域名可脱敏展示；个人内容不落库。
