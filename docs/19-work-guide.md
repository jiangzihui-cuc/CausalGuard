## 五、每天怎么工作（Git 流程）

```text
1. 从最新 main 拉分支：git checkout main && git pull
2. 建功能分支：       git checkout -b feature/模块名
3. 只做一件事，提交： git add <文件> && git commit -m "add ..."
4. 推送：             git push origin feature/模块名
5. 对方复核后合并 main
```

规则详见 [CONTRIBUTING.md](../CONTRIBUTING.md)。要点：
- `main` 只留可运行版本；
- 一次提交只解决一个问题；
- 不提交密钥、真实隐私数据、APK 大文件；
- 文档/规则变更与代码同一提交。
