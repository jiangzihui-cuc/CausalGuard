# 13 测试计划

> 版本：`v0.1`（P0 设计基线）
> 最后更新：2026-09-20
> 责任人：成员 B（协作：成员 A）
> 目的：在开发前确定“做完怎样算完成”。

## 1. 测试类型

| 类型 | 对象 | 方法 |
|---|---|---|
| 单元测试 | 规则、评分、脱敏、去重 | JVM 单元测试 |
| 事件关联测试 | 证据关联引擎 | 构造事件组合 |
| 规则命中测试 | 5-10 条规则 | 固定样例集 |
| VPN 连接与转发测试 | VpnService + 转发核心 | 测试机真实运行 |
| 授权拒绝测试 | 各权限 | 拒绝、部分授权、重复、撤销 |
| 断网测试 | 离线降级 | 关闭网络 |
| Demo 沙箱真值测试 | Demo App | 真值与预期输出一致 |
| 页面可用性测试 | 核心流程 | 非开发成员完成任务计时 |
| AI 事实一致性测试 | 解释模块 | 约束校验 |
| 稳定性测试 | 长时间运行 | 内存、崩溃、重启数据持久 |
| 多版本测试 | Android 10+ | 兼容矩阵 |

## 2. 测试优先级（P0）

| 优先级 | 测试 | 完成标准 |
|---|---|---|
| 高 | 权限拒绝不闪退 | 拒绝任一权限有清晰提示且不崩溃 |
| 高 | 事件时间线驱动 | 用固定 JSON 完整显示三类事件 |
| 高 | 重启数据不丢失 | 历史测试数据可恢复 |
| 高 | 规则稳定 | 同一输入同版本输出一致 |
| 高 | 证据可追溯 | 每条高风险结论能展开证据链 |
| 高 | 演示数据标识 | 演示事件与真实事件可区分 |
| 高 | VPN 启停与恢复 | VPN 停止后设备恢复联网；回收有降级 |
| 高 | 处置复查 | 处置后能展示变化或“无法确认” |

## 3. 授权场景测试

- 首次授权拒绝；
- 部分授权；
- 重复授权；
- 运行中撤销授权；
- 返回系统设置后状态更新。

## 4. 数据与隐私测试

- 断网时核心摘要仍可用；
- AI 不新增事实（事实一致性测试）；
- 删除数据后敏感内容不可恢复；
- 导出 PDF 不含敏感原文。

## 5. 用例记录与缺陷管理

- 维护测试用例表（编号、输入、预期、实际、通过/失败）；
- 维护缺陷清单：复现步骤、严重度、修复、回归；
- 保留运行截图/日志作为材料。

## 6. 验收门

- 核心演示流程无阻断性缺陷；
- 关键权限拒绝时有清晰提示，不闪退；
- 高风险结论没有无证据来源；
- 演示数据与真实数据明确区分。
