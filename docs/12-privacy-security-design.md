# 12 隐私、安全和合规设计

> 版本：`v0.1`（P0 设计基线）
> 最后更新：2026-09-20
> 责任人：成员 B（协作：成员 A）

## 1. 隐私设计目标

本项目本身是隐私工具，必须默认本地优先，采集最小化，让用户可暂停、可删除、可导出。

## 2. 数据留存边界

| 数据 | 处理 | 是否留存 |
|---|---|---|
| 事件元数据 | 存本地 | 是（可配置保留天数） |
| App 画像 | 存本地 | 是 |
| 风险结果/处置记录 | 存本地 | 是 |
| 剪贴板内容 | 不采集、不持久化 | **否** |
| 通讯录内容 | 不采集 | **否** |
| 精确位置轨迹 | 不保存坐标 | **否** |
| 聊天内容/请求体 | VPN 不查看 | **否** |
| 网络域名 | 可脱敏展示 | 是（元数据） |
| AI 输入 | 只发白名单字段 | 不保存敏感原文 |

## 3. 安全控制

| 控制 | 说明 |
|---|---|
| 本地优先 | 原始事件尽量只存设备端 |
| 剪贴板/通讯录 | 只记录“发生读取”及必要哈希/长度 |
| 网络域名 | 脱敏展示；不在演示使用真实账号、手机号、通讯录 |
| 云端字段过滤 | AI 请求前执行字段白名单（见 11），禁止上传原始敏感内容 |
| 数据控制 | 提供“暂停监测”“删除本地数据”“导出我的报告” |
| 演示标识 | 所有模拟事件显式标注“演示数据” |
| VPN 说明 | 明确告知读取网络元数据，不读取内容 |

## 4. 用户控制流程

- 暂停监测：停止 VPN 采集与 Usage 轮询，保留历史数据；
- 删除本地数据：清空事件库、画像、处置记录，二次确认；
- 导出报告：导出前字段过滤，不含敏感原文与精确轨迹；
- 授权撤销：状态变化时停止对应采集并提示。

## 5. 合规与原创声明

- 不做无障碍服务、不做 TLS 中间人、不自动撤销其他 App 权限；
- 涉及第三方开源代码、素材、模型时注明来源和版本；
- 若参考或复用 TrackerControl，明确 GPL-3.0 及代码边界，不换名套壳；
- 涉及地图时标注有效地图审图号（本项目 P0 不涉及地图底图）；
- 现场演示前核对大赛官网对时间、材料和公网连通性的最新要求。

## 6. AI 合规

- 记录模型名称、版本、调用时间、输入字段白名单、输出状态，不保存敏感原文；
- 最终文档填写 AI 大模型名称与版本、接口方式和 AI 辅助代码比例；
- AI 输出受本地校验约束，不创造事实。

## 7. 术语使用规范（防过度声称）

| 情况 | 允许措辞 | 禁止措辞 |
|---|---|---|
| 仅拥有权限 + 联网 | “声明了权限”“观测到网络连接” | “读取了位置”“发生数据泄露” |
| 后台敏感访问(Demo) | “演示事件：后台读取剪贴板” | 冒充真实系统采集 |
| 未知归属 | “无法归属到具体应用” | 强行归因 |
| 无法观测 | “无法从系统可靠获得” | 给出确定结论 |
| 规则推断 | “规则推断，置信度低” | 表述为系统事实 |

## 8. 验收检查

- [ ] 剪贴板/通讯录原文不落库、不上云；
- [ ] AI 请求只发白名单字段；
- [ ] 暂停/删除/导出均可用且导出不含敏感原文；
- [ ] 演示数据有标识；
- [ ] 术语符合规范，无过度声称；
- [ ] 第三方依赖与许可证已在文档登记。
