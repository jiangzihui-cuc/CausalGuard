## Definition of Done

- [ ] 在正确的短任务分支，不是直接修改 `main`；
- [ ] 开始前已 fetch 并基于最新 `origin/main`；
- [ ] 有唯一主责、明确输入、输出和验收证据；
- [ ] 受影响测试通过；
- [ ] 新增第三方代码/数据已固定版本并登记许可证；
- [ ] unknown、权限拒绝、断网和缺失数据有降级；
- [ ] PR 已由另一人 review，CI 通过；
- [ ] 合并后 `main` 可编译且主演示链未破坏。
