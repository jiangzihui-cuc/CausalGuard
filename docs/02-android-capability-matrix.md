# 02 Android 能力边界表

> 版本：`v0.1`（P0 设计基线）
> 最后更新：2026-09-20
> 责任人：成员 B（协作：成员 A）
> 验收标准：每个产品功能都能指向一个真实数据来源，不能出现“先写页面，之后再想数据从哪里来”。

## 1. 用途

把技术方案中的“可以、部分可以、不能可靠获得”变成开发依据。每一行是一个可观测能力，必须写清来源 API、是否需要授权、版本差异、能否作为真实证据、失败降级、是否只能放入演示沙箱、界面措辞。

## 2. 能力边界总表

| 能力 | 来源 API | 需授权 | 版本差异 | 能否作为真实证据 | 失败降级 | 界面措辞 |
|---|---|---|---|---|---|---|
| App 包名/UID/版本 | `PackageManager` | 部分（Android 11+ 需 `QUERY_ALL_PACKAGES` 或可见性声明） | Android 11 包可见性收紧 | 是（声明与身份事实） | 只展示系统已可见 App | “已安装应用” |
| 声明权限 | `PackageManager.getPackageInfo` | 否 | 稳定 | 是（声明了权限） | 无 | “声明了该权限” |
| 当前授权状态 | `PackageManager.checkPermission` / `PermissionInfo` | 否 | 稳定 | 是（当前是否获授权） | 无 | “当前权限状态” |
| 权限是否**刚被使用** | `AppOpsManager`（仅自身/受限） | — | 对其他 App 不可靠 | **否** | 不输出 | 不可表述为“使用了权限” |
| 前后台/近期使用 | `UsageStatsManager` | 是（Usage Access） | API 21+；后台刷新受限 | 是（使用上下文） | 缺授权则只用网络事件 + Demo | “使用状态（需授权）” |
| 屏幕/交互事件 | `UsageStatsManager` / `PowerManager` | 是 | 厂商定制差异 | 部分 | 降级为未知 | “可能处于使用中/未知” |
| 网络连接元数据 | `VpnService` | 是（VPN 授权） | Android 10+ 可用；用户可在系统随时断开 | 是（观测到的连接） | 无法归属时显示 unknown | “观测到网络连接” |
| 域名线索 | VPN 会话中解析（不含 TLS 中间人） | 是 | 加密 DNS/DoH 时不可见 | 部分 | 只能显示 IP/类别 | “域名线索（可能不完整）” |
| 流量/端口/协议 | `VpnService` | 是 | 稳定 | 是 | 无 | “网络流量” |
| UID 归属 | 自建 UID→包名映射 + `ConnectivityManager` | 是 | 多用户/工作资料差异 | 部分 | 显示“无法归属” | “无法归属到具体应用” |
| 阻断规则是否生效 | 本地转发/丢弃计数 | 是 | 依赖转发核心 | 是（本机规则事实） | 记录尝试但无法判定结果 | “已阻断/仍有尝试” |
| 剪贴板读取 | Android 官方限制，第三方 App 无法可靠后台读取他人剪贴板 | — | Android 10+ 后台剪贴板访问被限制 | **仅 Demo App 可提供真值** | 只能走演示沙箱 | “演示事件：后台读取剪贴板” |
| 位置调用历史 | 第三方 App 无法可靠读取他人完整定位历史 | — | — | **否** | 走 Demo App 真值 | “演示事件/有限观测” |
| 通讯录访问历史 | 第三方 App 无法可靠读取他人访问历史 | — | — | **否** | 走 Demo App 真值 | “不可观测，需用户自查” |
| 相机/麦克风访问历史 | 第三方 App 无法可靠读取 | — | — | **否** | 走 Demo App 真值 | “不可观测” |
| 原始剪贴板/通讯录内容 | 不采集 | — | — | 否 | — | 不展示、不保存 |

## 3. 三档可观测性定义

| 档位 | 定义 | 产品处理 |
|---|---|---|
| A 档：系统可直接观测 | 官方 API 能稳定返回事实 | 作为真实数据展示 |
| B 档：需要用户授权 | 用户授权后可获得，但可能被拒绝或回收 | 显示“需授权”，缺失时降级 |
| C 档：只能推断或仅 Demo 可得 | 无法从系统稳定获得，只能由 Demo App 提供真值或从元数据推断 | 进入演示沙箱，界面明确标注“演示事件”或“推断” |

## 4. 证据等级

| 等级 | 名称 | 含义 | 界面标签 |
|---|---|---|---|
| E1 | 系统事实 | 官方 API 直接返回 | 系统事实 |
| E2 | 授权观测 | 用户授权后通过 VPN/Usage 获得 | 授权观测 |
| E3 | 规则推断 | 由规则基于事实推导 | 规则推断 |
| E4 | 演示真值 | Demo App 提供的受控事件 | 演示数据 |
| E5 | 无法确认 | 证据不足或方法不可靠 | 无法确认 |

结论必须附带证据等级；E3 及以上不得使用“已发生泄露”等确定性措辞。

## 5. 关键限制声明（写入界面与文档）

1. `PackageManager` 只能说明 App 声明了什么权限、当前是否获授权，**不能证明 App 刚刚使用了该权限**。
2. 不能依赖 `AppOpsManager` 稳定监控其他 App 的全局敏感 API 调用。
3. 不能把“拥有权限 + 建立网络连接”直接表述为“发生了数据泄露”。
4. HTTPS 请求体通常不可见，首版不做 TLS 中间人解密。
5. 普通第三方 App 无法可靠读取其他 App 的完整定位、相机、麦克风或通讯录访问历史。
6. 自研 Demo App 提供可重复的敏感访问真值。

## 6. 失败降级矩阵

| 失败情形 | 触发信号 | 降级动作 | 界面表现 |
|---|---|---|---|
| VPN 无法稳定转发 | 测试设备频繁断网 | 采用成熟转发方案或收缩网络范围；保留离线回放 | 显示“网络观测不可用”，核心分析仍可用 |
| UID 无法归属 | 大量连接显示 unknown | 明确显示“无法归属”，降低结论等级 | 事件标记“无法归属” |
| 域名不可见 | 只见 IP 或加密 DNS | 使用 IP/类别降级 | 显示 IP 与推测类别，不强行生成域名结论 |
| Usage Access 被拒绝 | 无前后台事件 | 使用网络事件 + Demo 模式继续演示 | 显示“使用上下文不可用” |
| VPN 被系统回收 | 授权被撤销/断开 | 停止采集并提示 | 显示“监测已暂停” |
| 断网 | 无外网 | 核心功能本地运行 | 显示离线可用的功能范围 |
