# 06 模块设计说明

> 版本：`v0.1`（P0 设计基线）
> 最后更新：2026-09-24
> 责任人：成员 A（协作：成员 B）
> 状态：**接口骨架已冻结（A2-3/A2-5，2026-09-24）**；主要接口定义在 `core-model` 模块，Room 实现延后到阶段 3。

每个模块统一记录：目标、输入、输出、依赖、主要类/接口、错误处理、权限要求、测试方法、首版边界。

## M1 App 能力画像模块

| 项 | 内容 |
|---|---|
| 目标 | 提供已安装 App 的包名、UID、版本、声明权限、授权状态、场景类型 |
| 输入 | `PackageManager` |
| 输出 | `AppProfile` |
| 依赖 | 无（展示层使用画像聚合） |
| 主要接口 | `AppProfileRepository.getAll(): Flow<List<AppProfile>>` |
| 错误处理 | 包名不可见/被隐藏 → 只展示可见项 |
| 权限 | Android 11+ 包可见性（`QUERY_ALL_PACKAGES` 或 query 声明） |
| 测试 | 注入 mock 包列表 |
| 边界 | 不证明 App 刚使用了权限 |

## M2 使用上下文模块

| 项 | 内容 |
|---|---|
| 目标 | 判断某时刻 App 的前后台与近期使用状态 |
| 输入 | `UsageStatsManager` 查询结果 |
| 输出 | `foregroundState`（前台/后台/近期使用/长时间未使用/未知） |
| 依赖 | 权限状态模块 |
| 主要接口 | `UsageContextRepository.lastState(pkg, ts)` |
| 错误处理 | 无 Usage Access → 返回 `UNKNOWN` 并标记降级 |
| 权限 | Usage Access |
| 测试 | 注入伪造 Usage 数据 |
| 边界 | 无法稳定获取时仅作辅助信号 |

## M3 VPN 网络观测模块

| 项 | 内容 |
|---|---|
| 目标 | 观测网络连接元数据并归属 UID |
| 输入 | `VpnService` 的包/TCP/UDP 事件 |
| 输出 | `NetworkEvent`（IP、端口、协议、时间、流量、UID、域名线索） |
| 依赖 | 转发核心；UID→包名映射 |
| 主要接口 | `VpnObserver.start()/stop()`；`NetworkEventSource.events(): Flow<NetworkEvent>`（见 [TrackerControl Adapter 边界](trackercontrol-adapter-boundary.md)） |
| 错误处理 | VPN 被回收 → 停止并提示；UID 未知 → 显示“无法归属” |
| 权限 | VPN 授权 + 前台服务 |
| 测试 | 测试机真实连接 + 离线回放固定事件 |
| 边界 | 不查看请求体；域名不可见时只给 IP |

## M4 统一事件库

| 项 | 内容 |
|---|---|
| 目标 | 存取所有事件，供页面与规则读取 |
| 输入 | 各采集器输出的标准 `PrivacyEvent` |
| 输出 | 事件流、按 App/时间聚合 |
| 依赖 | Room；契约（09） |
| 主要接口 | `PrivacyEventRepository.insert(...)`、`observeAll()`、`byApp(pkg)`（接口在 `core-model`，实现在阶段 3） |
| 错误处理 | 写入失败入队重试；异常退出不丢历史数据 |
| 权限 | 无 |
| 测试 | 模拟事件注入；重启后数据持久 |
| 边界 | 是唯一写入口，规则不直接写原始事件 |

## M5 证据关联引擎

| 项 | 内容 |
|---|---|
| 目标 | 把事件、App、上下文、规则命中关联成证据链 |
| 输入 | `PrivacyEvent` + `AppProfile` + 规则结果 |
| 输出 | `EvidenceLink[]` |
| 依赖 | 事件库、画像、规则引擎 |
| 主要接口 | `EvidenceEngine.build(eventId): List<EvidenceLink>` |
| 错误处理 | 缺少证据 → 只构建已证明事实的链 |
| 权限 | 无 |
| 测试 | 构造事件组合验证关联 |
| 边界 | 证据等级缺失时降级为“无法确认” |

## M6 场景知识库

| 项 | 内容 |
|---|---|
| 目标 | 定义常见 App 场景的合理行为范围 |
| 输入 | 场景类型（计算器、天气、地图、社交等） |
| 输出 | 场景模板（合理权限、合理联网、合理前后台） |
| 依赖 | 无（数据驱动） |
| 主要接口 | `ScenarioLibrary.lookup(sceneType)` |
| 错误处理 | 未知场景 → 返回保守默认 |
| 权限 | 无 |
| 测试 | 覆盖合理/不匹配样例 |
| 边界 | 首版先覆盖四类场景 |

## M7 风险规则引擎

| 项 | 内容 |
|---|---|
| 目标 | 分类、评分、场景一致性判断、输出风险结果 |
| 输入 | 事件 + 画像 + 上下文 + 场景知识库 |
| 输出 | `RiskAssessment` |
| 依赖 | 场景知识库、画像、事件契约（10） |
| 主要接口 | `RiskRuleEngine.assess(input: RuleInput): RiskAssessment`（见 10 契约 §6） |
| 错误处理 | 规则异常 → 返回最低置信度，不阻断 |
| 权限 | 无 |
| 测试 | 规则命中测试、稳定性测试（同版本同输出） |
| 边界 | 不修改原始事件；不发明事实 |

## M8 解释与 AI 模块

| 项 | 内容 |
|---|---|
| 目标 | 将结构化结果转成人话，受证据约束 |
| 输入 | 脱敏后的 `RiskAssessment` + 模板 |
| 输出 | 解释文案、每日摘要 |
| 依赖 | 规则结果、契约（11）、脱敏模块 |
| 主要接口 | `Explainer.explain(assessment)` |
| 错误处理 | AI 不可用 → 本地模板兜底 |
| 权限 | 联网可选 |
| 测试 | 事实一致性测试 |
| 边界 | 不新增事件之外的事实 |

## M9 处置与复查模块

| 项 | 内容 |
|---|---|
| 目标 | 生成建议、执行阻断/设置跳转、记录并复查 |
| 输入 | 风险结果 + 系统设置路径 |
| 输出 | `Recommendation`、`MitigationRecord`、对比报告 |
| 依赖 | 事件库、规则引擎 |
| 主要接口 | `MitigationRepository.record(...)`、`review(pkg)` |
| 错误处理 | 设置路径不存在 → 提示手动操作 |
| 权限 | 系统设置跳转；VPN 阻断 |
| 测试 | 处置前后对比测试 |
| 边界 | 不自动改其他 App 权限 |

## M10 Demo App / 演示沙箱

| 项 | 内容 |
|---|---|
| 目标 | 提供可重复的敏感访问真值 |
| 输入 | 演示场景触发 |
| 输出 | 带 `isDemo=true` 的事件（4 个场景） |
| 依赖 | 事件契约 |
| 主要接口 | `DemoScenario.run(id)` |
| 错误处理 | 场景依赖权限不可用 → 提示 |
| 权限 | 演示 App 自身权限 |
| 测试 | 真值一致性测试 |
| 边界 | 事件必须明确标注演示 |

## M11 页面展示模块

| 项 | 内容 |
|---|---|
| 目标 | 渲染首页、告警、时间线、详情、画像、设置 |
| 输入 | ViewModel State |
| 输出 | UI |

| 测试 | 页面可用性测试、空状态测试 |
| 边界 | 不直接调用原始 Android 采集 API |

| 项 | 内容 |

| 依赖 | 无 |
