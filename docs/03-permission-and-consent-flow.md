# 03 权限与授权流程

> 版本：`v0.1`（P0 设计基线）
> 最后更新：2026-09-20
> 责任人：成员 B（协作：成员 A）

## 1. 目标

设计首次授权引导，解释每项权限用途、拒绝后果和停止监测方法。保证：拒绝权限不闪退、状态可恢复、真实与演示模式清晰区分。

## 2. 权限清单

| 权限/能力 | 系统入口 | 是否必需 | 用途说明（面向用户） | 拒绝后果 |
|---|---|---|---|---|
| VPN（`VpnService`） | 系统弹窗授权“连接请求” | P0 必需（网络观测） | 读取网络连接的目标地址与流量，用于判断是否向第三方服务发送数据；不查看聊天内容 | 无法进行真实网络观测，只能使用 Demo/离线模式 |
| 使用情况访问（Usage Access） | 设置 → 特殊应用权限 → 使用情况访问 | P0 建议 | 判断 App 处于前台还是后台，解释行为是否符合场景 | 缺少前后台上下文，风险结论降级 |
| `POST_NOTIFICATIONS` | 运行时权限（Android 13+） | P0 建议 | 发送实时隐私告警通知 | 无通知，仅应用内告警 |
| `QUERY_ALL_PACKAGES` | Manifest 声明（Android 11+ 上架需说明） | P0 建议 | 枚举已安装应用及权限状态 | 只能看到系统可见的 App |
| 网络状态 `ACCESS_NETWORK_STATE` | 安装即授权 | 是 | 判断当前是否联网，做离线降级 | 无法判断联网状态 |
| 前台服务 | Manifest + 通知 | 是 | 维持 VPN 观测与监测服务 | 监测可能被系统回收 |

> **不申请**与产品能力无关的权限（定位、通讯录、相机、麦克风、剪贴板等）。剪贴板/位置/通讯录的“访问行为”由 Demo App 提供真值，不要求主 App 申请敏感运行时权限。

## 3. 首次启动授权流程

```text
启动
  -> 隐私说明页（本地优先、不采集原始内容、可随时停止）
  -> 逐项申请：
       1) 通知权限
       2) 使用情况访问（跳转系统设置，返回后检测状态）
       3) VPN（系统连接请求弹窗）
  -> 每项显示：用途 / 后果 / 状态（已授权、未授权、被撤销）
  -> 全部处理完后进入首页
  -> 未授权项在首页以“待授权”卡片持续提醒，不阻断使用
```

设计原则：

- 先说明，后申请；一次只申请一项，避免系统连续弹窗。
- 任一项拒绝都可继续，进入对应的降级模式。
- 提供“暂停监测”和“删除本地数据”入口。
- 不要求用户授权任何与“观测他人 App 内容”相关的权限。

## 4. 状态检测与恢复

| 能力 | 检测方式 | 时机 |
|---|---|---|
| 通知 | `NotificationManagerCompat.areNotificationsEnabled()` | 启动、回到前台 |
| 使用情况访问 | `AppOpsManager` 检查自身 `OPSTR_GET_USAGE_STATS` | 启动、返回设置后、回到前台 |
| VPN | `VpnService.prepare()` 返回 null 表示已授权；服务运行状态 | 启动、Service 状态回调 |

## 5. 异常流程

| 场景 | 处理 |
|---|---|
| 拒绝 Usage Access | 首页提示“使用上下文不可用”，风险结论标注降级；提供再次授权按钮 |
| 拒绝 VPN | 进入离线/演示模式；真实网络事件不可用；提示恢复方法 |
| 部分授权 | 只启用已授权能力，未授权能力显示“待授权” |
| 重复授权 | 幂等处理，不重复申请，更新状态 |
| 撤销授权（运行中） | 监听状态变化，停止对应采集，提示“监测已暂停”，保留历史本地数据 |
| VPN 被系统回收 | 前台服务尝试恢复；失败则提示并提供手动重启 |
| 断网 | 核心分析本地运行，提示公网增强功能不可用 |

## 6. 停止监测与数据控制

- “暂停监测”：停止 VPN 采集与 Usage 轮询，保留历史数据；
- “删除本地数据”：清空事件库、画像、处置记录，二次确认；
- “导出我的报告”：导出前执行字段过滤，不含剪贴板原文、通讯录原文和精确位置轨迹；
- 所有 Demo 数据带“演示数据”标识，与真实数据在同一列表中也可区分。

## 7. 界面文案模板

| 类型 | 模板 |
|---|---|
| 授权说明 | “我们需要【能力】来实现【目的】。你可以随时在系统设置中关闭它。” |
| 降级提示 | “【能力】当前不可用，因此【结论】的可信度降级为【等级】。” |
| 演示数据 | “演示数据：该事件由 Demo App 产生，用于展示产品逻辑。” |
| 不可观测 | “当前无法从系统可靠获得该信息，因此我们不给出确定结论。” |

## 8. 验收检查

- [ ] 拒绝任一权限不闪退，且有清晰提示；
- [ ] 每项权限都有用途、后果、状态展示；
- [ ] 授权可撤销、可恢复，状态实时更新；
- [ ] 暂停监测后不再产生对应采集事件；
- [ ] 删除数据后敏感内容不可从 App 恢复。
